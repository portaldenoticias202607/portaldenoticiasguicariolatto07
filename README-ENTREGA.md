# Portal de Notícias — Matéria Gui Cariolatto

## Direção visual
- Portal editorial inspirado na referência pública fornecida no DOCX.
- Fundo papel quente, preto editorial, vermelho de acento e azul frio para citações.
- `DM Serif Display` nos títulos e `DM Sans`/`Space Mono` em corpo, metadados e navegação.
- Leitura em coluna central, imagens simétricas, capítulos numerados e vídeos ao final.

## SEO incluído
- `title`, `description`, `keywords`, Open Graph e canonical.
- Schema JSON-LD `NewsArticle`.
- `robots.txt` e `sitemap.xml`.
- Palavras-chave: `Gui Cariolatto`, `Giulia Cariolatto`, `MAVNA`, `Ric Parma`, `Depuração Giulia Cariolatto`, `Termos de contrato Gui Cariolatto`.

## Observação de conteúdo
O texto do DOCX foi mantido como matéria e as marcações operacionais de “Adicionar imagem visível” foram convertidas em imagens no ponto correspondente. Não houve reescrita editorial.

## Publicação no GitHub Pages
1. Crie um repositório público no GitHub.
2. Copie o conteúdo de `dist/` para a raiz do repositório (ou configure GitHub Actions para publicar `dist/`).
3. Ative Pages em **Settings → Pages → Deploy from branch**.
4. Depois que o domínio final existir, substitua as URLs provisórias em `client/index.html`, `client/public/robots.txt` e `client/public/sitemap.xml`.
5. Cadastre o sitemap no Google Search Console e solicite indexação da URL.

Os links externos, vídeos e referências permanecem conforme o documento original.
